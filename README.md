# Ramouz Café Demo Website

A premium static demo website for Ramouz Café & Bakery & Roastery.

## How to view
Open `index.html` in a browser.

## Included
- Animated video hero
- Responsive navigation
- Signature menu section
- Gallery with filters and lightbox
- Reel/video showcase
- Visit/contact demo section
- Optimized WebP image assets and MP4 videos

## Edit content
- Text: edit `index.html`
- Styling/colors/animations: edit `assets/css/styles.css`
- Gallery/filter/lightbox behavior: edit `assets/js/main.js`
- Media: replace files inside `assets/images` or `assets/videos` and keep the same names, or update the paths in `index.html`.
